# ШИНА+ — тестовый PWA-прототип

Демо для записи на шиномонтаж и рабочего кабинета мастерской. Интерфейс на русском, адаптирован для телефона и компьютера.

## Запуск

Требуется Node.js 18 или новее. В PowerShell из папки проекта выполните команду: node server.js

Откройте http://localhost:4173. Для показа на другом устройстве опубликуйте папку на HTTPS-хостинге.

## Что работает в демо

- Публичная страница мастерской: услуги, цены, адрес, часы работы и ближайшие свободные окна.
- Четырёхшаговая запись: услуги, автомобиль и размер колёс, время, контакты и согласие.
- Кабинет исполнителя: обзор дня, заявки, список записей, расписание по постам, клиентская база и настройки.
- Добавление записи вручную, подтверждение, перенос, отмена и уведомления в интерфейсе.
- Настройка рабочих часов, выходных, количества постов, буфера и прайса.
- Демо-данные: 3 поста, 10 услуг и 30 записей.
- Установка PWA на поддерживаемых устройствах и базовый офлайн-кэш оболочки.
- Изменения хранятся в localStorage текущего браузера. Кнопка «Сбросить демо-данные» восстанавливает исходное состояние.

Чтобы открыть кабинет, быстро нажмите на логотип «ШИНА+» пять раз и введите пароль демо-входа: shina2026. После входа приложение запомнит доступ в этом браузере и будет открывать кабинет после перезагрузки.

## Границы прототипа

Это интерактивный прототип, не готовый к работе с реальными клиентами. Парольная форма и сохранение входа работают в браузере; пароль находится в клиентском коде, поэтому это не защита для реальных данных. В проекте нет сервера приложений, базы данных, реальной отправки SMS/Telegram/push, загрузки фотографий, онлайн-оплаты, LLM-функций и защищённого хранения персональных данных. Уведомления об изменении записи показываются только как демо-сообщения. Расписание и запрет пересечения слотов работают в браузере и не защищают от одновременного бронирования на нескольких устройствах.

## Для производственного запуска

Потребуются Next.js/TypeScript-приложение с серверной проверкой доступности слотов, PostgreSQL/Supabase с RLS и ограничением пересечений постов, аутентификация сотрудников, защищённые персональные ссылки для клиентов, согласованный текст политики обработки персональных данных, интеграция уведомлений, домен и HTTPS. Перед запуском нужно заменить демо-адрес, телефон, часы и цены мастерской.
